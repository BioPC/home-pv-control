The importer supplied defaults only when a helper was absent (None). Present
helpers with an empty HA text state reached strict_json(''), which correctly
rejected that string. All four optional JSON helpers for PV1–PV10 were present
and blank, producing exactly 40 false-positive invalid_json_payload issues.
