5. VERIFICATION, RECOVERY AND SETTLING
Verification matches operation/controller/configuration signature/owner epoch/dispatch identity and adapter evidence source. Fresh post-dispatch HA readback must agree with the representable target. OpenDTU evidence additionally requires poll-start after dispatch, receive-after-poll, age <=120 seconds, established device/serial matching, credible rating/relative limit and Ok status. Enphase requires observed readiness.
Stale target-shaped values, command cache, startup assumptions, elapsed time and legacy helper state cannot prove successful physical operation. Verdicts are diagnostic only and cannot clear retained execution uncertainty or restore obligations.
Restart durably changes armed/in-flight work to unknown, retains original identities and reconstructs missing restore obligations. Missing archived full-power data remains an explicit unknown required target. A replacement controller in the same slot cannot satisfy old work.
Settling interprets fresh directional PV response, large-change stability and distinct samples. Two stable samples are required for a large change. Timeout is an explicit fallback and never physical restoration proof.

7. HOME ASSISTANT INCOMPATIBILITIES FOUND
The read-only expansion exposed a genuine minimum-version Number API difference: HA 2025.12.0 reads legacy value; the newer version uses native_value. The new count facade now implements both, without weakening assertions or changing its behavior.
The historical minimum test stack's aiodns 3.5.0 is incompatible with pycares 5.x. requirements-test-ha-minimum.txt pins pycares 4.11.0 to make that exact historical environment reproducible. Production requires no additional dependency.
Phase A also corrected test instrumentation for slotted ServiceRegistry and HA removing runtime_data on unload; these were test harness defects, not production lifecycle changes.

8. PROOF OF THE HARD WRITE BLOCK
The coordinator, fleet/adapters/recovery diagnostics and authorization entity return literal False. No configuration, import, enable intent, reload or observation can turn that into True.
There is no service dispatcher or executable adapter method. Plans contain frozen action/data/target records only. Native source has no hass.services.async_call, inverter-affecting service helper, MQTT actuator or HTTP write transport. The single HTTP session method is GET of the fixed OpenDTU status endpoint, allow_redirects=False.
AST checks reject actuator service access/transports/execution interfaces. Runtime service-call traps cover setup, validated setters, refresh, read-only polling, restart reconciliation, reload and unload. Both real HA versions assert the authorization sensor is Off. No live inverter or HBC command was sent; no live HA installation was modified.

9. DEVIATIONS AND PRACTICAL LIMITS
- The source's pre-write-already-full shortcut is deliberately not used as restoration authority in this read-only stage. Verification conservatively requires post-dispatch evidence; the shortcut needs separate operation/maintenance lifecycle tests later.
- When original configuration-range archives are unavailable, reconstructed restore targets stay unknown and recovery remains required. Current-slot/replacement settings are never substituted.
- The trusted OpenDTU rating cache is config-entry runtime state, not persisted across restart. Fresh API evidence or the manual fallback is needed afterward.
- Manual entity-ID rename aliases are tracked within the entry runtime. A stale manual reference after restart needs an explicit configuration update. Auto-detected renamed Enphase controls are rediscovered from metadata.
- Evidence verdicts and settling are exposed/tested data logic; this stage does not automatically finalize ledger operations or execute a policy/allocation loop.
- Intended entity IDs may receive suffixes beside legacy registry owners. This is reported; no entity is seized or deleted.
All requested read-only modules and phases are implemented within these stated limits. No physical-write, ownership or cutover scope was added.
