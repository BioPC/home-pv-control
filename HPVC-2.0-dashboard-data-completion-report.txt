6. ACCURACY / FORMULA
Native observed grid target-band metric, not the v1.6 counterfactual/causal loss
attribution model. Eligibility requires a known verified executed mode and finite
grid readback no older than 180s, with a new grid measurement timestamp.
error_W = observed_grid_W - configured_Target_Export_W
within = abs(error_W) <= configured_PV_Adjust_Deadband_W
accuracy_percent = 100 * within_count / measured_count
MAE_W = sum(abs(error_W)) / measured_count
RMSE_W = sqrt(sum(error_W squared) / measured_count)
sampled_coverage_percent = 100 * measured_count /
  (measured_count + unavailable_count + duplicate_count)
Zero measured samples => unavailable, never invented zero accuracy. Unavailable,
unknown/stale/nonfinite and overflow samples are excluded and counted. Duplicate
timestamps are separately counted. Coverage is sampled attempts, not whole-day
duration. Each observation uses its then-current target/deadband. Native evidence
does not establish the v1.6 Control/Load/PV/Other estimated-loss breakdown; those
fields remain unavailable with that difference disclosed.
